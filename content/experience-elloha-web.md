# Développeur Web chez elloha

**Période** : 2014 - 2017 (3 ans)

## Missions principales

- Développement de sites web sous le CMS DotNetNuke
- Création et personnalisation de sites pour des acteurs du tourisme

## Réalisations notables

Sites développés pour des destinations touristiques majeures :

- collioure.com
- tourismegard.com
- morbihan.com
- Et d'autres sites du secteur touristique

## Stack technique

- DotNetNuke (CMS)
- Développement web front-end

## Contexte

Premier poste chez elloha, spécialisé dans les solutions digitales pour le tourisme.
Cette expérience a posé les bases d'une carrière dans le développement web et la compréhension des besoins métier du secteur touristique.
